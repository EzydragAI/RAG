# Deep Dive into RAG — Classroom Site

Interactive one-hour lesson on Retrieval-Augmented Generation. Built with Next.js 16, React 19, Tailwind CSS v4, Motion, KaTeX, and React Flow.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- `/` — start screen
- `/learn` — timed lesson player (arrow keys / Space, `F` fullscreen)
- `/quiz` — 10-question live assessment

## Production build

```bash
npm run build
npm start
```

The original slide deck is saved at `reference/original-slides.html`.
